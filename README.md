# 【王国大学习】NIKKE 战术整备室

NIKKE Workshop 是一个 Chromium 浏览器扩展，集成账号角色数据获取、妮姬图鉴与列表管理、装备词条读取、洗词条目标设置、有限状态 MDP 计算和 Excel 导出。

当前版本：`1.0.0`

> 本项目是非官方玩家工具，与 SHIFT UP、Level Infinite、Tencent 或《胜利女神：妮姬》官方无隶属或授权关系。使用账号数据获取功能前，请自行了解相关服务条款与风险。

## 主要功能

- 在本地保存单账号信息、Cookie 和可选的 `area_id`
- 从 Blablalink 获取账号已拥有妮姬及其装备词条
- 浏览完整妮姬图鉴，并按爆裂、职业、代码、武器和企业筛选
- 管理“已获得”“常用”和自选妮姬列表
- 提供推图、异常拦截、辅助、个突主 C、企业塔等推荐方案
- 读取四件装备现有词条，设置独立或全局目标
- 使用有限状态 MDP 计算洗词条建议与预期石头消耗
- 汇总并导出妮姬计算结果 Excel
- 内置完整抓取冷却、异常响应重试和轻量熔断

## 安装

1. 前往 [Releases](https://github.com/ChrisLu7899/NIKKE-Workshop/releases) 下载最新版 `NIKKE-Workshop.zip`。
2. 将 ZIP 完整解压到一个固定文件夹。
3. 在 Chrome 打开 `chrome://extensions/`。
4. 开启右上角“开发者模式”。
5. 点击“加载已解压的扩展程序”，选择包含 `manifest.json` 的文件夹。
6. 打开扩展侧边栏开始使用。

更新时建议覆盖原文件夹并在 `chrome://extensions/` 点击“重新加载”，不要随意更换加载路径，以免扩展 ID 变化后无法继续读取原本的本地数据。

## 基本使用流程

1. 在侧边栏打开“账号信息”，填写账号信息或导入账号。
2. 使用“登录测试”或“更新 Cookie”确认登录状态。
3. 进入“NIKKE 战术整备室”，选择妮姬列表并同步账号数据。
4. 同步成功后可下载数据，或切换到洗词条计算器。
5. 为具体妮姬设置目标条件并运行有限状态 MDP。
6. 在“全部结果”中查看或导出最终汇总。

账号密码、Cookie、角色数据和计算结果默认保存在浏览器扩展的本地存储中。项目不提供云端账号同步服务。详细请求行为和风险边界见 [数据获取与请求安全说明](docs/数据获取与请求安全说明.md)。

## 本地开发

环境要求：Node.js `24.x`、npm、Chrome 或其他 Chromium 浏览器。

```powershell
npm ci
npm run lint
npm test
npm run build
```

构建结果位于 `dist/`。加载开发构建时，在浏览器扩展页面选择该目录。
