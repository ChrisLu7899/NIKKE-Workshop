# 【王国大学习】NIKKE 战术整备室

NIKKE Workshop 是一个面向 Chromium 浏览器的本地扩展，集成账号角色数据获取、妮姬图鉴与列表管理、装备词条读取、有限状态 MDP 洗词条计算和 Excel 导出。

当前版本：`1.0.8`　｜　支持：Google Chrome、Microsoft Edge

> 本项目是非官方玩家工具，与 SHIFT UP、Level Infinite、Tencent 或《胜利女神：妮姬》官方无隶属或授权关系。使用账号数据获取功能前，请自行了解相关服务条款与风险。

## 主要功能

- 从 Blablalink 获取账号已拥有妮姬、等级、突破和装备词条数据
- 在浏览器本地保存 Cookie、角色数据、计算目标和历史结果
- 浏览完整妮姬图鉴，并按爆裂、职业、代码、武器和企业筛选
- 管理“全图鉴”“已同步”“已录入”“常用”和自选妮姬列表
- 无需同步账号即可录入标准角色、创建自定义角色，并在本地导入或导出独立图鉴 Excel；导出文件包含角色卡展示页、九类装备效果总览、头部／身躯／臂部／腿部明细及可往返的锁定状态
- 可选使用阿卡机器人生成的 API Key，一次性读取国服或外服角色突破与装备词条；Key 仅存在于当前弹窗内存中，不保存、不导出、不写入日志
- 全图鉴末尾内置国服独占角色“画皮”和“婴宁”，并提供本地头像及完整职业、属性、爆裂、企业和武器资料
- 支持从安装目录的 `screenshots` 角色文件夹导入装备截图；可在完整游戏截图中确认红色 `OVERLOAD` 标识并按固定几何关系定位白色装备面板，再通过三条固定栏边界分别识别词条、档位数值与锁定状态，兼容稀疏词条与 15 档深色行，全程在本地处理
- 提供推图、异常拦截、辅助、个突主 C、企业塔等推荐方案
- 读取四件装备现有词条及其实际 1/2/3 号位置，设置独立或全局目标
- 在角色卡片显示装备词条最高的四项汇总，并在计算器中展示完整“装备效果一览”
- 无需同步账号即可手动录入四件装备，使用“四装备全局模拟”计算跨装备目标
- Blablalink 不提供词条锁定状态；计算前可对照游戏手动勾选“已锁”
- 支持点击词条序号强制保留现有词条，并正确计入首次锁定与后续锁定成本
- 使用有限状态 MDP 计算洗词条建议与预期石头消耗，并提供可逐级展开的完整决策树
- 全局模式通过通用候选生成、跨装备邻域搜索和精确 MDP 复核，寻找期望成本更低的目标分配
- 当前列表存在角色数据时，可直接导出角色卡式本地图鉴 Excel；无数据时按钮保持禁用
- 汇总洗词条结果并导出 Excel
- 内置请求冷却、异常响应重试和轻量熔断

## 安装

1. 前往 [Releases](https://github.com/ChrisLu7899/NIKKE-Workshop/releases/latest) 下载 `NIKKE-Workshop.zip`，不要下载 GitHub 自动生成的 Source code 压缩包。
2. 将 ZIP 完整解压到一个固定文件夹。
3. Chrome 打开 `chrome://extensions/`；Edge 打开 `edge://extensions/`。
4. 开启“开发者模式”。
5. 点击“加载未打包的扩展程序”或“加载解压缩的扩展”，选择可以直接看到 `manifest.json` 的 `NIKKE-Workshop` 根目录。
6. 确认扩展出现在列表中且处于启用状态。

更新扩展时，建议覆盖原文件夹并在扩展程序页面点击“重新加载”。不要随意更换加载路径，以免扩展 ID 改变后无法继续读取原本的本地数据。

## 首次使用

1. 打开扩展侧栏，点击顶部的“登录”，在新标签页进入 Blablalink。
2. 选择账号所在区域，填写账号和密码并完成验证登录。
3. 返回扩展，点击“保存/更新 COOKIE”。服务器区域按实际账号选择；`area_id` 通常留空，仅在自动识别失败时手动填写。
4. 进入“NIKKE 战术整备室”的“妮姬”标签页，点击“同步账号数据”；如果暂时不能同步，也可以从“全图鉴”录入标准角色，或新建自定义角色。
5. 同步完成后默认显示预设的“常用”列表；可切换到“已同步”查看账号内全部已同步妮姬，或切换到“全图鉴”浏览所有角色。
6. 页面顶部可通过“自定义角色”“图片识别”“阿卡数据”“本地数据”四个入口录入；底部在任何列表都保持“同步账号数据”“导出图鉴”两个操作。导出仅包含当前列表中确实带有等级、突破、战斗力、好感度或装备词条数据的角色，没有可导出数据时按钮为禁用状态。文件和图片只在扩展本地解析；若使用“阿卡数据”，需主动填写在阿卡中通过 `#ApiKey` 获取的 Key，并确认浏览器提出的阿卡接口访问权限。
7. 进入“洗词条计算器”，选择单装备模拟、四装备全局模拟或具体角色，设置目标并运行有限状态 MDP。
8. 在“全部结果”中查看最后一次计算结果并导出 Excel。

正常情况下，同步结果会保存在浏览器本地，无需每次打开扩展都重新获取。角色等级、突破或装备词条变化后，再次同步即可更新。

## 隐私与请求说明

账号、Cookie、角色数据和计算结果仅保存在浏览器扩展的本地存储中，不会上传至本项目服务器。获取账号数据时会与 Blablalink 进行必要通信；只有用户主动打开“阿卡数据”、填写 Key 并授予可选的 `pinkuro.top` 访问权限后，扩展才会向阿卡接口发送该 Key 并读取角色数据。阿卡 Key 不会保存、导出或写入日志。

Cookie 代表当前登录状态，请勿向他人分享 Cookie、完整日志或未脱敏的账号截图。请勿进行高频、批量或自动定时请求。详细请求行为、重试机制和风险边界见[数据获取与请求安全说明](docs/数据获取与请求安全说明.md)。
