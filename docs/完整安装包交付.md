# 完整安装包 · 1.0.11

1.0.11 正式分发唯一完整安装包。下文保留 2026-09-09 的 1.0.10 本地候选验收记录，旧版本号、包摘要及“未发布”描述仅表示当时状态；本次发布结果以 GitHub v1.0.11 Release 为准。

2026-09-09 按用户要求恢复单一完整安装包。安装和更新统一使用 `NIKKE-Workshop.zip`，包含当前全部 623 张立绘、头像、装备和技能图标、OCR 模型与插件程序。无需额外下载立绘。

## 当前行为

- 角色卡直接读取安装目录图片；保留图片失败占位、背景切换、构图、模块显隐和 PNG 导出。
- 移除侧栏与调整背景中的“立绘素材”入口，以及素材专用的可选权限。历史缓存保留但不再读取。
- 插件和 Windows 更新器只选择完整包，忽略轻量包、素材包和源码包；兼容完整包的版本后缀名称。
- 旧轻量候选安装可使用新版更新器迁移为完整安装；完整包覆盖其安装标识与图片清单。旧更新器若仍限制轻量包，可先手动解压新版完整包并重新加载扩展。
- 保留窗口显示与重复启动恢复、侧栏底部版本入口、SHA-256 校验、安装确认、备份、回滚、中断恢复及 screenshots 保护。不改变协议注册，不修改账号数据。

## 打包

以 `VITE_NIKKE_PRIVACY_MODE=false` 构建到新的临时目录，将当前 README、MODIFICATIONS、ASSET_SOURCES 复制到构建根层，然后运行 `scripts/package-installers.ps1`，传入 `BuildDirectory` 与全新 `OutputDirectory`。脚本仅生成一个 `NIKKE-Workshop.zip`，打包前逐张核对素材哈希，打包后逐文件回读 ZIP 校验。

构建仍生成素材完整性清单与 full 安装标识，供打包校验及旧候选迁移使用。旧可选下载模块保留在源码中作为撤回记录，应用不再引用，构建不包含其下载界面或缓存逻辑。旧拆包候选文件保留，不作为本次交付物。
