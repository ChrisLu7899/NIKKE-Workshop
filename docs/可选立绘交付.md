## 使用与范围

- 完整安装：`NIKKE-Workshop.zip`，包含全部 623 张 WebP。
- 轻量安装：`NIKKE-Workshop-Lite.zip`，不含上述大图；头像、企业／职业图标、装备图标、魔方、收藏品物件、角色技能图标、OCR 模型和代码均保留。
- 独立素材：`NIKKE-Workshop-Artwork.zip`，仅适用于相同素材清单的离线补充。内含素材清单、原图目录及来源许可，不是可加载扩展。确认清单 revision 与当前扩展相同后再解压到原扩展根目录；不同版本不要混装。
- 范围包含默认立绘、皮肤、国服立绘、珍藏品背景及技能动画静态背景，不包含动态视频或游戏原始资源。
- 无立绘时角色卡使用占位，数值和图标继续显示，仍可导出数据卡。插件侧栏底部与调整背景面板提供“立绘素材”；首次点击下载需要浏览器确认可选权限。不会打开角色就自动联网下载。

## 存储和更新约定

下载内容保存在当前扩展的 Cache Storage（`workshop-artwork-sha256-v1`），不写安装目录或 screenshots。缓存键使用内容 SHA-256，不随程序版本改变。保持安装目录、浏览器配置及扩展 ID 的原地更新会保留；卸载扩展、清空扩展数据或更换浏览器不能自动迁移。

程序更新优先选择轻量 ZIP。完整安装的原图文件、原始安装选择与已安装清单不被轻量包覆盖；旧完整安装没有清单时继续逐图核验实际文件。轻量安装拒绝强制完整更新。更新器代码可以升级，协议注册独立保存，路径不变无需重新启用。

下载最多 4 个并发，单文件超时 45 秒。按文件校验字节数、WebP 文件头和 SHA-256，成功后才缓存。暂停、断网、关闭页签会保留已完成图片；继续只补缺失或损坏文件，不做文件内断点续传。多页同时下载受 Web Lock 限制。打开的角色卡在下载结束或暂停后刷新本地图片。请保持下载页签打开。

## 版本、安全与素材来源

构建生成 `artwork-manifest.json`：应用版本、素材 revision、每张图片路径／大小／SHA-256 和不可变 Git 提交。当前来源提交为 `916b6c1fa50ff6b3ecfce4e8591e1020ed95aed2`，下载仅指向本项目 `ChrisLu7899/NIKKE-Workshop` 的该提交。构建图片与提交 Git blob 不一致时不生成可下载来源，提示使用完整包；即使提交未公开，404 也会安全停止并保留已完成内容。

原图沿用已验收产物，未重新裁切或转换；随包保留原有来源清单和 ASSET_SOURCES。可选下载不携带登录凭据，禁止任意下载地址、重定向、相对路径越界及超限文件。安装包整包 SHA-256 校验与图片逐文件校验相互独立。

## 构建候选包

只从新构建目录打包，禁止以真实验收目录作为 Vite 输出目录。先复制当前 README、MODIFICATIONS、ASSET_SOURCES 至新构建根目录，再执行：

```powershell
$env:VITE_NIKKE_PRIVACY_MODE='false'
npm run build -- --outDir .tmp/zip-builds/<本轮唯一目录>
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/package-installers.ps1 -BuildDirectory .tmp/zip-builds/<本轮唯一目录> -OutputDirectory <全新候选输出目录>
```

脚本不覆盖既有发布包，生成 package-report.json 记录文件数量、大小与 SHA-256。完整和轻量包的代码与功能图标一致；只有原图与安装标识不同。
