# 1.0.15 发布验证（2026-10-16）

## 范围

保留单件、批量与四装备的 Web Worker 流程，移植转移数组、阈值求解、概率及全局配置缓存、保守剪枝等性能优化；最终结果保留完整决策树。默认旧规则，可选新规则。普通同步失败重试间隔改为 10 秒，成功间隔、服务端限流与熔断保护保持原状。纳入此前验收的角色立绘和本地头像更新。

## 实际验证

- lint、348 项全量测试、正式构建、git diff --check 全部通过。
- 正式构建设置 VITE_NIKKE_PRIVACY_MODE=false；ZIP 根目录为扩展文件，无源码、测试、缓存和账号数据；1,333 个文件均逐项回读核验。
- 从最终 ZIP 解压后，Edge 与 Google Chrome for Testing 155.0.8059.84 在独立配置目录加载扩展，核对 Manifest 1.0.15；没有使用个人浏览器配置或账号。
- 两种规则下单装备、四装备真实 Worker 求解、完整决策树和下一层分支均通过。单件期望分别 28.4516445753 / 26.7305334642；四件样例分别 22.7666176467 / 22.6796320008。
- 暂停 requestAnimationFrame 并隐藏计算区域时，Worker 仍完成求解。此测试不代表操作系统休眠后仍可运行。
- Chrome 正式渠道已限制命令行加载未打包扩展，因此正式渠道另做 HTTP 页面冒烟，扩展安装检查由官方 Chrome for Testing 完成；未声称已经手工操作 Chrome 正式渠道的安装界面。
- Edge 与 Chrome for Testing 的真实扩展环境中，南瓜女巫本地头像及立绘、水晶女仆、神秘学者皮肤均成功解码显示；无页面异常。
- 转移概率、逐状态策略、缓存键和剪枝等正确性证据另见《计算优化验证-20261016.md》。
