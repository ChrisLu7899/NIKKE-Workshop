安装目录右侧新增“选择目录”，使用 Windows 文件夹选择器。选中合法安装根目录后读取其 manifest 版本、事务目录及待恢复状态，并清空旧 Release 信息、进度和确认勾选。用户重新确认目录后再检查更新；操作不移动插件文件，也不自动更改协议注册，需另点“启用插件唤起”才更新后续唤起位置。

## 当前限制

- 仅 Windows 独立更新器及包含全量立绘的完整安装包。
- 活跃事务不提供强制取消按钮。强行结束进程后，下次启动先恢复未完成事务。备份保留在当前用户 LocalAppData，不自动清理。
- 依赖审计仍有 ExcelJS 间接 uuid 的两项中等级告警；已观察到 ExcelJS 使用 v4 无 buffer 调用，未发现公告所列 v3/v5/v6 buffer 调用路径。未执行会造成主依赖降级的强制修复，这不等于对依赖安全作绝对保证。
- Vite 保留既有大分块体积警告，功能回归通过；字体授权、非 T10 OCR 等未完成工作不在本次更新器交付范围内。
