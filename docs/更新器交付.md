# 1.0.10 更新器交付记录

## 实现范围

插件只检测官方 GitHub 最新稳定 Release、显示版本和发布说明，并通过 `nikke-workshop://update` 请求打开 Windows 独立更新器。首次手动运行安装目录中的 `Workshop-Updater.vbs`，核对目录后启用插件唤起。没有 Native Messaging、扩展 ID 绑定、常驻服务或静默安装。

更新器再次获取官方 Release，核验安装包名称、来源、版本、大小和 SHA-256；用户确认后下载、暂存、逐文件备份并覆盖，最后更新 Manifest。失败回滚；中断后再次运行可恢复未完成事务。不会降级。`snapshots` 和 `screenshots` 按大小写不敏感规则永久保护，安装包中的同名条目跳过，不清理用户目录或旧文件。URI 参数不参与命令、下载地址或安装目标构造。

## 验证

- Lint、308 项测试、关闭开发隐私模式的全新构建、diff 空白检查通过。
- ZIP 根层和全部 1324 个文件逐项 SHA-256 校验，解压后在独立测试资料目录的 Chrome 152 和 Edge 中验证新版／同版／旧版／离线状态、桌面和窄屏、仅唤起不安装。
- 装备普通／企业／OVERLOAD 图标、角色卡模块与 PNG 导出、练度 OCR 合并保存回归通过；测试不使用真实浏览器账号。
- Windows 自有窗体检查真实 GitHub 元数据；事务测试覆盖损坏包、路径穿越、ADS、8.3 别名、链接／目录联接、磁盘门禁、应用失败回滚、中断恢复；以唯一临时协议实测 ShellExecute 唤起后忽略 URI 参数，随后移除该测试键。未替用户注册正式协议。
- 安装包和对应源码包发布后必须重新下载校验；具体提交、附件哈希与时间保存在本地发布报告和 GitHub Release 中。

## 当前限制

- 仅 Windows 独立更新器及完整安装包；轻量包另行实现。
- 活跃事务不提供强制取消按钮。强行结束进程后，下次启动先恢复未完成事务。备份保留在当前用户 LocalAppData，不自动清理。
- 依赖审计仍有 ExcelJS 间接 uuid 的两项中等级告警；已观察到 ExcelJS 使用 v4 无 buffer 调用，未发现公告所列 v3/v5/v6 buffer 调用路径。未执行会造成主依赖降级的强制修复，这不等于对依赖安全作绝对保证。
- Vite 保留既有大分块体积警告，功能回归通过；字体授权、非 T10 OCR 等未完成工作不在本次更新器交付范围内。
